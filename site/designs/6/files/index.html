Files and fields

Each file carries an about line, the snapshot time, a fields guide and its items. Images stay on the market's site; media.json lists each one with the sizes WordPress made and a credit. Any page or tool can fetch them.

data/site.json

Site name, tagline, menus and social links. Menus are read from the public homepage, as the menus API needs a login.

  • navigation main menu; items with children are dropdowns
  • topbar the small bar above the header
  • footer_1, footer_2, bottom_bar footer menus
  • social official social profiles linked from the site
  • logo_file local copy of the logo under site/

data/exhibitors.json 40

Stallholders (WordPress post type 'portfolio', shown on the site as Stallholders).

  • id WordPress id
  • slug URL slug
  • name stall name
  • categories ids into categories.json exhibitor_categories
  • description_html cleaned HTML
  • description_text plain text
  • image id into media.json
  • links outbound links in the description (their own websites, Instagram)
  • date first published, UTC
  • source_url the stallholder's page on the official site

data/posts.json 103

Journal posts (news, market highlights, tasting notes, recipes ...).

  • date published, UTC
  • categories ids into categories.json post_categories
  • tags ids into categories.json tags
  • excerpt plain text
  • body_html cleaned HTML (null when the post uses page-builder blocks)
  • blocks page-builder content as blocks (see pages.json)
  • image id into media.json
  • source_url the post on the official site

data/pages.json 18

Public pages. The site's page builder (WPBakery / Uncode) shortcodes are converted to plain blocks.

  • blocks section > column > heading | text | button | image | gallery | listing | embed | form
  • image the page's header image, id into media.json
  • source_url the page on the official site

data/posters.json 19

The market's own posters: the animated GIF banners in its media library, oldest first.

  • url the full animated GIF on the market's site (some are large)
  • sizes smaller copies WordPress made (usually still, not animated)
  • bytes file size of the full GIF

data/categories.json

Exhibitor categories (portfolio_category), journal categories and the tags in use.

  • count number of items in WordPress

data/media.json 380

Every image the snapshot uses. All images belong to Chiswick Cheese Market and are used here only to show their own content back to them.

  • file local copy under site/ (at most 1600 px wide)
  • original_url the image on the official site
  • credit credit line

Using the files

In a browser:

const r = await fetch('data/exhibitors.json');
const { items } = await r.json();
items.filter(e => e.categories.includes(6)).map(e => e.name);

On the command line, with jq:

jq -r '.items[] | select(.categories | index(6)) | .name' data/exhibitors.json

Straight from WordPress (their API, public and read-only):

curl 'https://www.chiswickcheesemarket.uk/wp-json/wp/v2/portfolio?per_page=20&_fields=id,slug,title,portfolio_category'
