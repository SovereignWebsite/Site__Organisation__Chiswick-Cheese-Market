The parser

The site's pages are built with a page builder (WPBakery, in the Uncode theme). The API returns them as raw shortcodes, like [vc_row][vc_column width="1/2"][vc_custom_heading]..., with the quotes typographically "curled". The toolkit straightens the quotes, parses the shortcodes into a tree and keeps only what a design needs: sections, columns, headings, text, buttons, images and listings.
